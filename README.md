# SQL Aggregate Functions Assignment

**Author:** Thon Yien Thon

## Description
This assignment demonstrates the use of SQL aggregate functions in MySQL to analyze data from the `payments`, `customers`, and `orderdetails` tables.

## Tasks Completed
1. Calculated total payments for each payment date and displayed the five latest dates.
2. Calculated the average credit limit for each customer.
3. Calculated the total price of products ordered.
4. Found the highest payment amount for each check number.

## SQL Concepts Used
- `SUM()`
- `AVG()`
- `MAX()`
- `GROUP BY`
- `ORDER BY`
- `LIMIT`

## Tools Used
- MySQL
- MySQL Workbench

- `Answer.sql` – Contains all four SQL queries.
